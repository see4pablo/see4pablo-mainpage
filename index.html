  • SheetQuery

    Filter a spreadsheet on your computer, type short expressions, paste age-and-sex counts into Excel or Sheets. Nothing uploads here.

    Input

    Age,Sex,Diabetes,Smoker
42,M,YES,NO
43,F,YES,YES
41,M,NO,NO
55,F,YES,NO

    Queries

    Diabetes = YES
Diabetes = YES AND Smoker = YES

    Output (one row per query → paste into Excel)

    Query 40–44
    M · F    		 55–59
    M · F    		 …
    Diabetes = YES 1 · 1 0 · 1 …
    + Smoker 0 · 1 0 · 0 …

    Each cell is men · women in that age band. Clinic files may use SI/NO instead of YES/NO.
