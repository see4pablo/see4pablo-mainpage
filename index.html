  • SheetQuery

    Filter a spreadsheet on your computer, type short expressions, paste age-and-sex counts into Excel or Sheets. Nothing uploads here.

    Name Age Sex Diabetes Smoker

    Luis Soto 43 M YES YES
    Camila Ríos 41 F NO NO
    Diego Vega 55 M YES NO

    Queries

    Diabetes = YES
Diabetes = YES AND Smoker = YES

    Output (CSV → paste into Excel)

    Age 40-44 55-59 …
    Query M F M F …
    Diabetes = YES 1 1 1 0 …
    Diabetes = YES AND Smoker = YES 1 0 0 0 …
