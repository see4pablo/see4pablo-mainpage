SheetQuery

A small desktop tool for filtering spreadsheets and counting people by age band and sex. Ready to paste into Excel or Google Sheets.

dev.see4pablo.cl/sheetquery · runs on your machine

Downloads are offline packages. You put your data file next to the app; nothing is uploaded to this website. Workbooks may contain identifiable health data — keep them private.

Windows .zip · ready to unzip & run Mac .zip · when the build is published

After download

  1. Unzip the folder.
  2. Put your spreadsheet in the data folder.
  3. Run the app (or follow the README inside the zip).
  4. Open the batch_….csv in output and paste into your sheet.

Source and docs: github.com/see4pablo/sheetquery. Drop the release zips into downloads/ on this site (or point these buttons at a GitHub Release URL) when builds are ready.
